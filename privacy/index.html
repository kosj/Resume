방문 분석 안내

이력서가 어떤 경로로 발견되고 어떤 페이지가 조회되는지 파악하기 위한 방문 분석입니다. 수집 API가 연결된 이후의 방문부터 기록하며, 과거 방문 기록을 소급해 수집하지 않습니다.

기록하는 정보

  • 조회 시각과 이 사이트 내 페이지 경로
  • 세션의 첫 유입 Referrer 도메인과 공유 링크의 UTM 출처·매체·캠페인
  • 터치 포인터 또는 마우스·트랙패드 구분
  • 탭 단위 임시 세션 식별자의 서버 HMAC 값

분석 데이터베이스에는 IP 주소, 원본 User-Agent, 전체 Referrer 주소, 검색어, 임의의 URL 쿼리와 앵커를 저장하지 않습니다. UTM 값에는 개인정보를 넣지 마세요. 브라우저가 출처를 제공하지 않으면 직접 / 알 수 없음으로 집계합니다.

세션과 보관 기간

쿠키 대신 sessionStorage에 임의 식별자와 최초 유입 정보를 보관합니다. 한 탭에서 30분 동안 페이지 이동이 없으면 새 세션을 시작하며 탭을 닫으면 브라우저의 해당 저장소가 해제됩니다. 데이터는 Cloudflare Workers와 D1에서 처리하고 90일이 지난 기록은 일일 삭제 작업으로 제거합니다. 실제 데이터 조회는 관리자 키로 보호합니다.

분석 요청을 전달하는 과정에서 Cloudflare는 네트워크 연결에 필요한 IP 등 요청 정보를 처리할 수 있습니다. 서비스 운영자가 통제하는 분석 코드와 데이터베이스에는 원본 IP를 기록하지 않으며 Worker 호출 로그도 비활성화하도록 구성했습니다.

분석 참여 선택

Global Privacy Control 또는 Do Not Track이 활성화된 브라우저는 분석을 전송하지 않습니다. 아래 버튼으로 현재 브라우저의 방문 분석을 끌 수도 있습니다. 이 설정은 이 사이트의 localStorage에 저장합니다.
