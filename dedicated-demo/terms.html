영상설명용어집
1:20 · Unreal Engine · Dedicated Server · RPC · Replication

언리얼 데디케이티드 서버와 클라이언트 반영

이 영상에 나오는 용어 12개.

Authority
해당 Actor 상태에 대한 최종 권한을 가진 역할이다. 이 모형에서는 서버다.
Autonomous Proxy
소유 클라이언트가 입력·이동 예측을 수행하는 로컬 제어 Pawn 역할이다.
Dedicated Server
로컬 플레이어와 게임 렌더링 없이 서버 역할로 실행하는 프로세스다.
GameMode
서버에만 존재하며 게임 규칙을 처리한다.
GameState
클라이언트에 복제할 공용 게임 상태를 담는 Actor다.
Net Relevancy
Actor가 특정 연결에 복제될 필요가 있는지 정하는 조건이다.
NetMulticast
서버 호출 시 서버와 관련된 클라이언트에서 실행하는 RPC다. 과거 이벤트를 새 참가자에게 재생하지 않는다.
PlayerController
서버와 소유 클라이언트에 존재하며 플레이어의 제어를 담당한다.
RepNotify
복제 값 수신에 따라 클라이언트의 HUD 등을 갱신하는 콜백 방식이다.
SavedMove
이동 예측·서버 확인·보정 후 재실행에 사용하는 저장 이동 데이터다.
Server RPC
소유 연결 규칙에 따라 서버에서 실행하도록 요청하는 원격 함수 호출이다.
Simulated Proxy
서버에서 수신한 상태로 원격 Actor를 표현하는 역할이다.
