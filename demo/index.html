전투가 화면에 반영되기까지

움직이는 게임 안에서 전투 공통 로직·버프·투사체 풀링의 적용 흐름을 봅니다.

0:00 / 1:30

직접 조작 모드: WASD·방향키 이동 / Space 공격 / E 강화 / R 초기화. 모바일은 아래 버튼을 사용하세요.

이력서의 기술을 설명하기 위해 새로 구현한 별도 데모입니다. 기존 게임 녹화나 Unreal 실행 화면이 아닙니다. 두 모델은 같은 브라우저에서 독립 계산하며 실제 네트워크 통신은 하지 않습니다. 게임 수치는 예시입니다.

설명 읽기용어집MP4 영상사용한 제작 스킬

이력서에 적힌 결정론적 전투·스탯 공통 로직, 버프와 투사체 풀링을 작은 3D 게임으로 새로 구현했다. 캐릭터를 이동시키고 공격하면 실제 시뮬레이션 상태에 따라 투사체가 날아가고, 몬스터 HP와 누적 피해가 바뀐다. 이 데모는 실제 프로젝트의 소스·녹화·성능 측정 결과가 아니며 모든 게임 수치는 예시다.

이동 입력이 정수 좌표를 바꾸고, 공격 입력이 가장 가까운 생존 대상을 선택한다. 사거리 안의 대상이 있을 때 풀에서 투사체를 빌려 발사한다. 투사체 이동이 끝난 틱에 피해를 반영하고 슬롯을 반환한다.

예시 기본 공격력은 80, 방어력은 20이다. 강화가 없고 치명타가 아닌 경우 피해는 60이다. 실제 피해가 남은 HP보다 크면 남은 HP만큼만 적용한다. 시뮬레이션은 30Hz로 동작하며 실제 프로젝트의 틱 빈도를 나타내지 않는다.

클라이언트 모델과 서버 모델은 각각 새 상태를 만든 뒤 같은 입력 기록, 데이터, 시드로 전체 시뮬레이션을 독립 실행한다. 같은 틱의 위치·HP·난수 상태·누적 피해를 비교한다. 화면의 식별값은 주요 상태를 요약한 진단용 해시이며 일치만으로 모든 상태의 동일성을 증명하는 보안 검증값은 아니다.

두 모델은 하나의 브라우저 안에서 실행한다. 실제 서버 접속이나 패킷 동기화를 구현한 영상은 아니다. 이력서의 C++·C# 라이브러리나 Unreal 플러그인을 실행하는 것도 아니며, 동일 조건의 공통 계산이라는 원리를 설명한다. 같은 시드만으로 충분하지 않고 입력 순서·데이터·계산 규칙·난수 호출 순서가 같아야 한다.

강화 입력은 4초간 공격력 배율 1.5를 적용한다. 강화 상태에서 치명타가 아닌 공격은 공격력 80 × 1.5 − 방어력 20 = 피해 100이 된다. 20% 예시 확률의 치명타는 계산한 피해에 배율 1.5를 적용한다. 영상과 상태 창 모두 같은 실제 계산 결과를 사용한다.

스탯은 100을 1로 읽는 정수 스케일, 배율은 10,000을 1로 읽는 정수 스케일로 표현하고 연산 단계에서 소수 부분을 버린다. 이는 개념 시연용 규칙이다. 강화 오라는 상태의 남은 시간을 읽어 표시하며, 발사 시 강화 여부가 해당 투사체의 피해를 결정한다.

투사체 슬롯 6개를 미리 만들고 빈 슬롯을 빌려 쓴다. 발사 시 시작 위치·도착 위치·대상·피해·도착 틱을 채우고, 도착하면 피해를 반영한 뒤 비활성 상태로 반환한다. 슬롯을 다시 쓰면 재사용 횟수가 증가한다. 3D 투사체 메시도 6개를 만들어 슬롯과 연결한다.

표시하는 슬롯 수·발사 수·재사용 수는 이 데모의 실제 상태다. 풀링이 항상 더 빠르다는 성능 비교나 원래 프로젝트의 FPS 개선 수치를 제시하지 않는다. 이력서에 적힌 Actor·Niagara 풀링의 원리를 별도 구현으로 보여 준다.

같은 입력 기록을 처음 상태부터 다시 계산하면 동일한 전투 흐름을 볼 수 있다. 데모 페이지의 직접 조작 모드에서는 WASD나 방향키로 이동하고 Space로 공격, E로 강화한다. 초기화하면 시드와 상태가 처음으로 돌아간다.

새로 만든 교육용 기록 재생 기능이다. 판테라 일반 대전 리플레이를 구현했다는 의미가 아니며 해당 기능은 원본 이력서대로 미구현이다. 게임 수치와 화면 구성은 모두 예시다.

용어 정리

결정론적 계산
같은 초기 상태·입력·데이터·규칙과 난수 호출 순서에서 같은 결과를 얻도록 구성하는 계산이다.
고정 시드
의사 난수 생성기의 시작 상태다. 이 데모는 2026을 사용한다.
고정소수점
정수에 정해진 스케일을 적용해 소수를 나타내는 방식이다. 이 데모의 스탯 스케일은 100이다.
틱
게임 상태를 한 번 갱신하는 단계다. 이 데모는 예시로 초당 30틱을 사용한다.
버프
일정 시간 능력치나 행동에 영향을 주는 강화 상태다.
치명타
정해진 규칙에 따라 일반 피해에 추가 배율을 적용하는 공격이다. 이 데모는 예시 확률 20%·배율 1.5를 사용한다.
오브젝트 풀
객체를 미리 준비해 필요할 때 빌리고, 사용이 끝나면 반환해 재사용하는 구조다.
상태 식별값
일부 게임 상태를 요약한 진단용 해시다. 이 데모에서는 결정론적 계산을 확인하는 보조 수단으로 쓴다.
입력 기록
틱별 이동·공격·강화 명령의 기록이다. 초기 상태에서 다시 계산할 수 있다.
