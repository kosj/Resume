실제 방문 데이터 연결

관리자 화면은 준비되어 있습니다. Cloudflare 계정에서 수집 서버를 한 번 배포하면 실제 집계를 시작할 수 있습니다.

  1. 저장소를 받은 컴퓨터에서 backend 폴더로 이동하고 Cloudflare에 로그인합니다.
    npx wrangler@4 login
npx wrangler@4 d1 create resume-analytics
  2. 반환된 D1 ID를 backend/wrangler.toml의 database_id에 넣고 테이블을 생성합니다.
    npx wrangler@4 d1 migrations apply resume-analytics --remote
  3. 32바이트 이상의 서로 다른 무작위 비밀값 두 개를 생성해 안전하게 보관합니다. 아래 명령의 비밀 입력 프롬프트에 각각 관리자 키와 세션 해시 키를 입력합니다.
    npx wrangler@4 secret put ADMIN_TOKEN
npx wrangler@4 secret put SESSION_SALT
npx wrangler@4 deploy
  4. 배포된 Worker URL을 analytics/config.mjs의 API_BASE에 넣고 이 공개 설정을 커밋·푸시합니다. 관리자 키는 공개 코드에 넣지 않습니다.
  5. 관리자 페이지에서 API 주소와 관리자 키를 입력합니다. UTM 테스트 링크로 새 탭에서 방문한 뒤 조회하면 수집 여부를 확인할 수 있습니다.

배포 전에는 실제 기록을 수집하지 않으며 예시 데이터는 실제 방문과 구분해 표시합니다. 기존 방문의 소급 집계는 불가능합니다.
