이메일·메신저·채용 플랫폼은 유입 주소를 숨길 수 있습니다. 공유 링크에 UTM을 붙이면 출처별 집계가 가능합니다.

캠페인 값에는 이름·이메일 등 개인정보를 넣지 마세요.
집계 기준과 데이터 안내

방문은 한 탭에서 30분간 페이지 이동이 없으면 새로 시작하는 세션입니다. 새 탭·다른 브라우저는 별도 세션이므로 사람 수와 다릅니다. 브라우저의 뒤로 가기 캐시 복원·페이지 내부 앵커 이동은 새 조회로 세지 않습니다.

유입 출처는 UTM 우선, 이후 Referrer 도메인으로 분류합니다. 출처가 없는 방문은 직접 / 알 수 없음입니다. 원본 검색어는 수집하지 않습니다. 방문 표와 출처 표는 기간 내 시작한 세션 기준이며 페이지 조회는 기간 내 발생한 조회 기준이라 비율을 전환율로 해석하지 않습니다.

기기 분류는 터치 포인터 / 마우스·트랙패드의 구분으로, 휴대전화·태블릿·PC를 정확하게 식별하지 않습니다. 알려진 일부 검색·SNS 도메인을 분류하며 나머지는 외부 링크로 표시합니다. 상위 표는 각각 50개까지만 표시합니다.

분석은 브라우저에서 전송한 기록으로 차단기·추적 거부 설정·봇·조작에 영향을 받을 수 있습니다. 원본 IP·전체 Referrer·User-Agent·임의 URL 쿼리·앵커는 저장하지 않습니다. 데이터는 90일 보관 후 일일 작업으로 삭제합니다. 관리자 페이지 방문은 수집하지 않습니다.

관리자 화면의 HTML은 공개되지만 실제 집계 API는 관리자 키 인증이 필요합니다. 로그아웃하거나 페이지를 새로 고치면 메모리의 키가 사라집니다.
