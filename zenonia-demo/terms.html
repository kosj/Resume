A* 자동 길찾기와 서버·클라 락스텝

이 영상에 나오는 용어 9개.

결정론
같은 초기 상태·데이터·입력·규칙과 처리 순서에서 같은 결과를 얻는 성질이다.
공통 틱
비교할 모든 모델이 처리를 완료한 동일 시뮬레이션 시점이다.
락스텝
같은 틱의 입력을 같은 순서로 처리해 각 모델이 게임 상태를 계산하는 방식이다.
맨해튼 거리
가로 차이와 세로 차이의 합이다. 이 데모의 네 방향·동일 비용 격자에 사용한다.
열린 목록
발견했지만 아직 확정하지 않은 탐색 후보다.
입력 묶음
한 틱에 필요한 플레이어 입력을 순서대로 모은 데이터다.
A*
g+h를 기준으로 후보를 선택하는 경로 탐색 알고리즘이다.
g·h·f
g는 누적 비용, h는 남은 비용 추정치, f는 둘의 합이다.
no-op
해당 틱에 입력 변화가 없음을 명시하는 명령이다.
